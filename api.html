Book Finder

About this API

The API and why I chose it

I used the Open Library Search API, run by the Internet Archive. It searches millions of book records and returns titles, authors, and publication years in JSON. I chose it because it is free, needs no API key, and works with a simple GET request.

Where I found it

https://openlibrary.org/dev/docs/api/search

Parameters used

The request is: https://openlibrary.org/search.json?title=the+hobbit&limit=5

  • title – the book title to search for.
  • limit – the maximum number of results to return.

Where this API would be helpful

A library or used bookstore website could use this API to fill in a book's author and publication year automatically whenever the staff type in a title.
